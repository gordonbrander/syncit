# Guides

Short guides to the things you do with syncit, in reading order. If you haven't yet, start with the [quick start](https://github.com/gordonbrander/syncit#quick-start).

1. [Basics](basics.md): sync two folders, send changes one way with `push` and `pull`, copy files in with `cp`, check what a sync would do, read the output, and ignore files.
2. [Conflicts](conflicts.md): when the same file changed in two places, syncit keeps both. How to settle it, and when text files merge themselves.
3. [Version history](history.md): how many old versions to keep, snapshots, getting an old version back with `log` and `restore`, and who changed what.
4. [Partial sync](partial-sync.md): keep just part of a large backup on your laptop. Get more with `get`, free up space with `move` and `drop`.
5. [Remotes](remotes.md): sync through encrypted cloud storage. Set up a bucket (Cloudflare R2 example), credentials, and the secret key.

For every command at a glance, see the [command list](https://github.com/gordonbrander/syncit#commands).
